# Vibeisland 键盘猫美化设计

状态：用户已授权自主完成实现和验收。当前原生实现及验证以 docs/keyboard-squad-acceptance/README.md 为准。

## 已确认方向

- A 的黑色岛体、清晰系统字体、等宽数字与克制色彩。
- 黑耳奶白小猫趴在键盘后面，左右爪交替敲击；固定左侧耳斑。
- 动作由 Agent 状态驱动，不监听用户全局键盘输入。
- 十角色键盘小队，由系统自动分配，与任务固定绑定；重启后保留，不提供手动更换。供应商仍用原有名称和身份标识区分。

## 尺寸与排版

- 收起态角色显示框 30 × 26.25 pt；会话行 40 × 35 pt。实际图形包含黑色边距。
- 物理刘海区域保留为不可绘制区，角色、额度和命中区域都在可见区域内。原生尺寸最终以当前屏幕几何为准，浏览器示例不能证明硬件避让。
- 展开使用当前 430 pt 内容宽度作为基线；高度沿用真实会话数、场景和滚动上限计算，不固定为预览高度。
- 标题用系统字体，数字与重置时间使用等宽数字；供应商与任务来源持续可见。
- 用量保留已用/剩余原始语义，显示窗口、数值、重置时间和来源；缺少数据不编造读数。

## 动作与交互

| 状态 | 角色 | 窗口行为 |
| --- | --- | --- |
| 空闲 | 双爪落下、睁眼 | 安静待机 |
| 运行 | 约 240 ms 一拍，左右爪交替，周期内短暂停顿 | 不牵动文字或面板；不可见时停止帧更新 |
| 审批 | 停手、抬头 | 移出不自动收起；手动收起后保留提示 |
| 问答 | 停手、抬头，配独立问号与文字 | 保持当前回答/打开任务能力，不臆造可提交选项 |
| 完成 | 举爪一次，900 ms 后回到待机 | 2.2 秒后收起；鼠标或键盘焦点在岛内时继续停留 |
| 故障 | 停手、关切表情 | 错误文字和打开任务入口保留，不自动消失 |

- 悬停进入延迟 180 ms；移出缓冲 350 ms；重复进入取消离场计时。
- 展开与收起容器约 300 ms，内容晚 60 ms 开始淡入；去掉大面积模糊和过度回弹。
- 点击收起条切换展开；子按钮、会话行点击不同时触发容器收起。
- Esc 只收起视图，不作出审批决定、不终止任务。
- 保留当前命中区宽容范围，手动收起后 300 ms 内不因旧鼠标位置立即展开。
- 减少动态效果时禁用角色循环与庆祝，只保留 140 ms 过渡。文字、状态图标与键盘操作仍可用。
- 预览中的审批与问答是固定演示，不请求真实账户、不发送真实决定。

## 保留现有功能的落实方式

实现前按当前工作树逐项列出入口，不以早期历史文档作为功能清单。当前重点包括：

- 会话列表、任务跳转、供应商和来源标识、状态排序与滚动。
- 额度刷新、账户、设置、连接与错误提示、原有菜单栏入口。
- 审批请求允许的所有动作（拒绝、允许一次、始终允许、绕过等按请求能力展示），保留原有风险区分，不能缩减成预览中的两个按钮。
- 问答场景的真实任务入口；完成、断开与中断状态的原有含义。
- 全局快捷键、多屏、无刘海屏、点击穿透和焦点行为。

## 实现边界与检查

- 在现有 IslandShell / IslandSceneViews / IslandSprite 及动效配置上修改视觉；复用现有 store、provider、审批服务和任务跳转。
- 当前工作树存在其他未提交改动。实施前重新确认差异，避免覆盖已有工作；本轮文件均在独立预览目录。
- 生成图先作为黑底预览素材。原生资源需核验帧边界、对齐、小尺寸边缘与解码成本；失败时回退静态角色，状态文字不能消失。
- 不引入动画框架、全局键盘监听或新的模型调用链。
- 原生实现后运行相关状态/交互检查与项目要求的 make check、make test；真实账户和 Keychain 探针不属于本次视觉验收。
- 新构建的原生应用验证收起/展开、所有任务状态、任务跳转、按请求能力保留审批动作、快速进出、Esc、焦点、减少动态和双屏几何。
